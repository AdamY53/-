# 90度转弯编码器测试工程

这是从当前地图循迹工程复制出来的独立 Keil 工程，仅用于调整固定 90 度转弯参数。

## 测试动作

按一下 K1 后，小车依次执行：

1. 以原工程直行速度直行 1 秒；
2. 以原工程固定转弯差速 PWM 进行编码器闭环转弯；
3. 左右轮分别达到目标编码器计数后，停止转弯；
4. 再以原工程直行速度直行 1 秒；
5. 自动停止并保留 OLED 显示。

测试过程中再次按 K1，会立即停止并清空本次数据；完成或超时后按 K1 可重新测试。

## OLED 显示

- `L90/R90`：本次转弯阶段左右轮累计编码器计数；
- `T`：左右轮各自的有符号目标计数；
- `S`：当前阶段。

OLED使用普通 `OLED_8X16` 字体，便于直接观察左右轮转弯计数。

计数单位与原工程 OLED 的 `AVG` 编码器计数相同，但这里左右轮分开记录，不取平均值，也不是未经标定的“实际机械圈数”。

## 调参位置

参数位于 `User/main.c` 文件顶部：

```c
#define TEST_STRAIGHT_PWM            25
#define TEST_TURN_PWM                30
#define TEST_TURN_LEFT_TARGET        (-120)
#define TEST_TURN_RIGHT_TARGET       120
```

当前目标符号对应左转：左轮反向、右轮正向。若要测试右转，可交换两个目标的正负方向，例如：

```c
#define TEST_TURN_LEFT_TARGET        120
#define TEST_TURN_RIGHT_TARGET       (-120)
```

先观察 `L90/R90` 的实际值，再分别调整两个目标值。编码器异常时，`TEST_TURN_MAX_MS` 会触发超时保护并停止电机。
