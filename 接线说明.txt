避障小车接线说明
==================

本工程路径：E:\桌面\避障小车
芯片/工程风格：STM32F103C8T6 + STM32F10x 标准库 + Keil5

一、保留原工程基础接线
----------------------
1. OLED I2C
   SCL -> PB9
   SDA -> PB8
   VCC/GND 按原工程接线

2. TB6612 电机驱动
   STBY -> PB0
   左轮 AIN1 -> PB1
   左轮 AIN2 -> PB15
   左轮 PWMA -> PB3 / TIM2_CH2
   右轮 BIN1 -> PB13
   右轮 BIN2 -> PB14
   右轮 PWMB -> PA15 / TIM2_CH1

3. 编码器
   右轮编码器 E1A/E1B -> PA6/PA7 / TIM3
   左轮编码器 E2A/E2B -> PB6/PB7 / TIM4

4. 按键
   K1 -> PB10：启动/停止
   K2 -> PB11：OLED 页面切换
   K3 -> PB12：显示三路超声波页面

二、7 路红外循迹模块
--------------------
程序逻辑顺序：L3 L2 L1 M R1 R2 R3；OLED测试显示顺序：R3 R2 R1 M L1 L2 L3

L3 -> PA4
L2 -> PB4
L1 -> PA3
M  -> PA2
R1 -> PA1
R2 -> PB5
R3 -> PA0

说明：PB4/PB5 会关闭 JTAG，仅保留 SWD 下载，属于正常设置。

三、3 个 HC-SR04 超声波模块
---------------------------
前方超声波 US1：TRIG -> PA9，ECHO -> PA10
左侧超声波 US2：TRIG -> PA11，ECHO -> PA12
右侧超声波 US3：TRIG -> PC14，ECHO -> PC13

重要：HC-SR04 的 ECHO 通常是 5V 输出，STM32 输入脚是 3.3V，ECHO 必须用分压或电平转换。
所有模块必须和 STM32 共地。

四、当前程序功能
----------------
K1：启动/停止小车
K2：显示直线循迹调试页面
K3：显示三路固定超声波页面

直线循迹时小车按 7 路灰度传感器进行 PD 循迹；七路灰度全部丢线时停车。
遇到 90 度拐点时，程序先按编码器累计值固定直行一段，再用双电机反方向
差速 PWM 固定时间转弯，之后恢复循迹。OLED 循迹调试页里的 L/R/C 均为
编码器计数单位，可直接用于调整可调窗口。
OLED 超声波页面显示 F/L/R 三个固定模块最近一次测距，`--- E:n` 表示
本次没有收到有效 ECHO，n 为诊断状态码，不等同于距离为 0 cm。

当前 main.c 已精简，不包含 K230、串口收包、蜂鸣器、三色 LED、送药路径状态机。
